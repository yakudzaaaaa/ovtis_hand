# Сервер с кнопкой статуса, который можно изменить через адресную строку. 
## Чтобы начать работу надо: 
1. скачать и закинуть в адрес 2 файла(python и json)
2. открыть командную строку, через `cd путь к файлу` выбрать путь к файлам
3. написать py `app.py`
4. перейти по указанному адресу
5. работать
